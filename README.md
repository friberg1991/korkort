# Emils Körkort

Övningsfrågor för B-körkortets teoriprov, som app i mobilen.

Öppna <https://friberg1991.github.io/korkort/> och lägg sidan på hemskärmen.
Sedan fungerar den utan internet, och det du svarar sparas i mobilen.

Frågorna är skrivna med egna ord. Trafikbilderna är egna ritningar, och
vägmärkena är Sveriges officiella vägmärken.
